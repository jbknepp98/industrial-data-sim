# BluebirdBev: Connect mapping spec

Generated by `plant connect-spec`. Read-only Postgres source for Timebase Connect.

| Setting | Value |
| --- | --- |
| Host | `flow-data-sim-pg` (Timebase Docker network), or `127.0.0.1:5435` from the Mac |
| Database | `flow_data_sim` |
| User | `flowsim_reader` (read-only) |
| Password | In `~/flow-data-simulator/config/postgres.env` (`FLOWSIM_READER_PASSWORD`). Never paste it into specs or tickets. |
| Tables | 23, all named `bluebirdbev_<purpose>` |

## Polling rules

- **Watermark:** `row_version` is a bigint from one shared sequence, stamped on every insert and update. Poll `WHERE row_version > @watermark ORDER BY row_version`.
- **Keys:** each table's natural key (first column) is its primary key. Updates change the row in place (for example a ticket moving Open → Complete), so map by key.
- **`modified_utc`** is the simulated change time, for display only. Don't use it as a watermark.
- **Soft deletes:** `is_deleted` and `deleted_utc` exist for the connector contract. The simulator never deletes rows.
- **Live data:** rows appear when their simulated time arrives, so the latest row is about now and never in the future.
